# Модель вычислительной Вселенной

У автора следующая гипотеза:
- Элементарной частицей Вселенной является 1 бит (информации)
- Закон эквивалентности масса ~ энергия ~ информация
- Вселенная имеет CLK - время. Каждый элементарный тик "Вселенский вычислитель" обрабатывает модель и формирует картину мира (элементарные частицы и их взаимодействия)
- Элементарные частицы реализуют некую структуру данных сложной организации
- Протон тяжелее электрона примерно в 1836 раз, то есть в нём в 1836 больше информации. Это хинт, который позволит сформировать их структуры

Необходимо разработать вначале baseline модель водорода (протон + электрон) на базе классической квантовой механики (волновое уравнение), которое будет использоваться как эталон.

Далее необходимо разработать вычислительную модель (выбрать размерность, структуру данных, связность и топологию) которая бы укладывалась в квантовую модель атома водорода.

Написать отчёт о реализации, все формулы и тезисы.

Есть тонкие моменты вроде полей -- нужно додуматься как они проявляются в модели вычислительной вселенной -- это "побочные" эффекты или без них невозможно построить модель. Не будь заангажирован квантовой механикой, старайся честно идти в процессе исследования вычислительной модели.
